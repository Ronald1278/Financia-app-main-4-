## 📋 Sobre o Projeto

O Financia App é um aplicativo mobile desenvolvido como projeto de extensão acadêmica para a disciplina de Programação Para **Programação Para Dispositivos Móveis em Android**. O aplicativo tem como objetivo facilitar a vida de pessoas que possuem dificuldades para organizar e controlar suas finanças pessoais, principalmente em relação ao acompanhamento de gastos, receitas e planejamento financeiro.

## 🛠️ Como Executar o Projeto

### Pré-requisitos

- Node.js 
- npm ou yarn
- Expo CLI
- Emulador Android/iOS ou dispositivo físico

### Passos para Instalação

1. **Clone o repositório**
   ```bash
   git clone https://github.com/marcosbr29/Financia-app.git
2. **Instale as dependências**
   ```bash
   npm install
   # ou
   yarn install
3. **Inicie o projeto com Expo**
   ```bash
   npx expo start

4. **Execute no dispositivo/emulador**

Escaneie o QR Code com o app Expo Go (Android/iOS)

Pressione a para abrir no emulador Android
